How to Update TCG AGENCY

Steps

  1. 01. First go to application root directory & store your MySQL database & email credentials from the .env
  2. 02. Then in the applicaiton root direcotry upload the Update.zip and unzip it.
  3. 03. Go to your Setup python app from cPanel and open this application.
  4. 04. Now copy the update.txt and run pip install with it in the python application
  5. 05. Now run the command given bellow & run script.
  6. 09. Congratulations your TCG AGENCY is updated to version 1.5

Update command

  1. /home/cpanel_username/application_root_directory_name/manage.py update
